🚀 Инструкция по запуску проекта



Шаг 1. Подготовка базы данных

1. Откройте Командную строку (Win + R -> введите cmd -> Enter).
2. Запустите консоль базы данных и создайте БД:

CREATE DATABASE productdb;

3. Выполните команду в Командной строке для инициализации таблиц (перед этим переключите консоль на UTF-8, чтобы избежать проблем с русскими буквами):

chcp 65001

psql -U postgres -d productdb -f src/main/resources/db_init.sql


Шаг 2. Сборка проекта

В Командной строке перейдите в корневую папку проекта (где лежит pom.xml) и выполните команду сборки:

mvn clean package

В папке target\ будет создан файл productapp.war

Шаг 3. Запуск в Apache Tomcat 9

1. Скопируйте WAR-файл в каталог webapps вашего сервера. Пример команды:

copy target\productapp.war D:\Programming\Servers\tomcat9\apache-tomcat-9.0.112\webapps\

2. Запустите Tomcat: Перейдите в папку bin вашего Tomcat и дважды кликните по файлу startup.bat (или выполните bin\startup.bat из консоли).
3. Откройте приложение: Перейдите в браузере по ссылке:
   👉 http://localhost:8080/productapp/products/

🔑 Данные для входа
- Администратор: логин admin / пароль admin123
- Пользователь: создается через кнопку «Регистрация» на главной странице приложения.
